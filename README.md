# Amaturis — turismo app

Frontend de Amaturis para presentar experiencias y destinos turísticos con una interfaz web moderna y adaptable.

## Demo

[Ver aplicación desplegada](https://turismo-app-five-black.vercel.app)

## Stack

- Next.js
- TypeScript
- React
- CSS y componentes de interfaz
- Vercel

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para ver la aplicación.

## Build de producción

```bash
npm run build
npm run start
```
